# CS2ESP 使用说明（一键版）

## 这是什么

单文件透视工具：内核驱动读游戏内存 → 共享内存帧 → 外部覆盖层渲染。
不注入游戏、不修改游戏内存、不挂钩。

## 系统要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 **64 位** |
| 权限 | 必须以**管理员**运行（清单已强制 UAC） |
| HVCI / 内存完整性 | **必须关闭**（Windows 安全中心 → 设备安全性 → 内核隔离 → 内存完整性 → 关，重启） |
| 易受攻击驱动阻止列表 | 关闭（管理员 PowerShell：`reg add "HKLM\SYSTEM\CurrentControlSet\Control\CI\Config" /v VulnerableDriverBlocklistEnable /t REG_DWORD /d 0 /f`，重启） |
| 杀毒软件 | 把 `CS2ESP.exe` 加入白名单（火绒/Defender 会拦 kdmapper） |
| 显卡 | 支持 D3D11 即可 |

> 上面两条系统设置不满足时，驱动加载会失败，程序会提示
> `mapper exit 0x...` 或 `driver loaded but the shared frame section never became readable`。

## 使用步骤

1. 把 `CS2ESP.exe` 放到任意目录（路径不要含中文更稳）。
2. 双击运行，UAC 点「是」。
3. 程序会：检测驱动 → 没装则自动加载（约 1–3 秒）→ 等待 CS2 窗口。
4. 启动 CS2，进入地图。
5. 屏幕上出现方框/骨骼/名字即成功。
6. 按 **INS**（或 `HOME`）开关菜单。

菜单是中文的，分两页：

- **透视**：玩家方框、方框样式、骨骼、血条、护甲条、名字、距离、武器与弹药、弹匣数量、装备标记、C4 携带者、地面物品、投掷物、视线指示、屏幕连线、显示队友
- **雷达**：启用、点位样式、十字线、显示范围、缩放比例

## 命令行（可选）

| 参数 | 作用 |
|---|---|
| `--selftest` | 打印环境/资源/驱动/帧状态后退出（排障用） |
| `--driver-only` | 只加载驱动，不渲染 |
| `--force-driver` | 忽略"已加载"，强制再映射一次 |
| `--no-driver` | 只用已存在的驱动，不加载 |
| `--frame-check` | 打印当前帧的玩家/物品/投掷物 |

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击没反应 | UAC 被拒；右键「以管理员身份运行」 |
| `mapper exit 0x...` | 杀软拦截 / HVCI 未关 / blocklist 未关 |
| `driver not ready: administrator required` | 没有管理员权限 |
| 一直等 CS2 窗口 | 游戏窗口类名不是 `SDL_app`；用窗口化/无边框 |
| 方框整体偏移 | 确认游戏分辨率与显示一致；不要用「全屏独占」 |
| 开镜时框短暂消失 | 已在驱动侧缓存上一帧矩阵，正常情况下 1 帧内恢复 |
| 游戏更新后无框 | 需要重新 dump 偏移并重编（见开发者文档） |

## 卸载

驱动是手工映射的，**重启即消失**。程序退出后重启一次即可完全清理。

## 注意

- 本程序只读游戏内存，不保证在任何反作弊平台下不被检测；平台风控规则不公开。
- 分发前请确认接收方也满足上面的系统要求（HVCI、杀软白名单）。
