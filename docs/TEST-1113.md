## 1. 本次修掉的问题

| 现象 | 根因 | 修复 |
|---|---|---|
| 启动即 0xC0000005 | `CEntity::GetBone()` 在 `Pawn.Address == 0` 时返回空 `CBone`，`DrawBone` 访问空 vector 的 `[HEAD]`（偏移恰好 0xA8） | 改为返回 `BoneData` 引用；FillEntity 写非零哨兵 |
| 帧全是诊断态 `0xDEAD0002` | 驱动 `.sys` 还是 14196 编译的，游戏已更新到 14197 | 用本地 dumper 刷新 seed 并重编驱动 |
| 雷达中心错位 | header `localSlot` 与 `PF_LOCAL` 记录差一个槽位 | `LocalSlot()` 优先扫 `PF_LOCAL` |
| 菜单默认挡住画面 | `ShowMenu = true` | 默认 `false`，`HOME` / **`INS`** 切换 |
| 多实例 section 冲突 | 同 salt 的两份驱动抢同一个名字 | 驱动 `SALT=3`，显示端依次尝试 3→2→1 |

## 2. 测试步骤

> 每步都给出「操作 / 预期 / 判定 / 需要反馈」。按顺序做，任一步不通过就停在那一步反馈。

### T1 · 静止贴合

- **操作**：站定，视线正对 10–20 m 内一个队友，不要动鼠标。
- **预期**：白色矩形框左右贴肩、底边贴脚、顶边略高于头；青色骨骼从头到脚连续；名字在框上方，距离在框下方。
- **判定**：框边缘与模型轮廓偏差 < 10 px 视为通过；整体偏移（框比人高/低半个身位）记为不通过。
- **反馈**：截图（Win+Shift+S 框选该玩家）+ 偏差方向（偏上/偏下/偏左/偏右）。

### T2 · 移动跟随与延迟

- **操作**：按住 A/D 快速左右平移 2 秒，再跳跃一次。
- **预期**：框跟随模型，无肉眼可见拖尾；跳跃时框底边随脚离地。
- **判定**：拖尾 < 1 个身位视为通过；明显滞后（> 100 ms，约 1/6 秒）记为不通过。
- **反馈**：录屏 5 秒或描述拖尾程度（轻微/明显/完全跟不上）。

### T3 · 距离与血条

- **操作**：走到队友身边（约 3 m）→ 后退到约 20 m；再让队友受伤（或自己被击中）。
- **预期**：距离数字随之变化；血条长度与游戏内血量一致（左侧竖条，绿色→红色渐变）；有甲时右侧出现蓝色护甲条。
- **判定**：距离误差 < 2 m 通过；血条方向/长度反了记为不通过。
- **反馈**：实际距离 vs 显示距离（各报 2 组）；血条是否随受伤变化。

### T4 · 装备 / 武器 / 弹药

- **操作**：切主武器→副武器→刀；开一枪；按 R 换弹；购买护甲/头盔/拆弹器。
- **预期**：武器名随切换变化（AK-47 / Glock-18 / Knife）；`[数字]` 为弹匣余弹，开枪递减、换弹时出现 `R`；装备字母出现 `H`（头盔）/`K`（拆弹器）/`Z`（开镜）。
- **判定**：武器名与游戏内 HUD 一致、弹药数字跟随变化即通过。
- **反馈**：切枪后显示的名字；换弹时是否有 `R`；买甲后是否有 `H`。

### T5 · 物品与投掷物

- **操作**：把一把枪丢在地上；扔一颗烟雾/燃烧弹；观察 3 秒。
- **预期**：地面武器显示金色小框 + 名称（可能带 `(drop)`）；投掷物显示绿色圈 + 类型 + 距离，燃烧区为橙色半径圈。
- **判定**：能看到掉落物与投掷物即通过；位置明显偏离记为不通过。
- **反馈**：是否看到掉落物框；投掷物圈是否落在实际落点附近。

### T6 · 雷达

- **操作**：原地转视角 360°，观察左上角 Radar 窗口。
- **预期**：敌人点随视角旋转，点相对本地玩家的方位与游戏内一致；队友/敌人颜色不同（T 橙、CT 蓝）。
- **判定**：雷达点方位与游戏内小地图一致即通过。
- **反馈**：雷达点是否随转身旋转；方位是否对得上。

### T7 · 菜单与配置

- **操作**：按 **INS**（或 `HOME`）开关菜单；在 ESP 页取消/勾选 `BoxESP`、`BoneESP`、`ArmorBar`、`GearFlags`、`GroundItems`、`Grenades`；在 Radar 页调 `Proportion`。
- **预期**：菜单随按键开合；取消勾选后对应元素立即消失；雷达比例滑块生效。
- **判定**：每个开关都能即时改变画面即通过。
- **反馈**：哪个开关无效；菜单是否挡住准星（可通过拖动标题栏移动）。

## 3. 需要反馈的关键信息

1. **画面**：任一异常处的截图（Win+Shift+S），标注「哪个玩家、偏多少」。
2. **帧状态行**（左上角）：`seq / players / items` 三个数字，出现异常时截一张。
3. **具体现象**：偏框方向、拖尾程度、数值不符（实际 vs 显示）。
4. **崩溃**：若进程退出，记录是否弹窗；`docs` 下会有 `CS2ESP.pdb`，可用 cdb 抓栈。
5. **游戏内设置**：分辨率、全屏/无边框、是否开镜（影响 fov 相关表现）。

## 4. 已知限制（不是 bug，先不用反馈）

- `fov=0`：相机 FOV 读取失败（`m_pCameraServices` 偏移正确但时机不对），开镜时不做缩放；腰射画框不受影响。
- 方框是 1.4 px 白色细线，浅色墙面背景下对比度低；可在菜单里改 `BoxColor`。
- 投掷物只画当前位置 + 半径 + 出手点连线，没有落点弹道推演。
- 机器上现在有 3 份手工映射的驱动实例（调试遗留），重启后只剩正常使用的一份。
